# Bundled INDD reader

`indd.exe` is the Windows x64 release build of [indd-utils](https://github.com/storytold/indd-utils) at commit `136f973a9d5f1b3ef34e46e27f4a08af196efde7`, built with `cargo build --release` using Rust 1.100.0. The upstream source is available at that commit. The binary is redistributed under the included MIT license.
