# Local interface fonts

Inter (400, 500, 600, 700) and Newsreader (400, 500, 600), downloaded from Google Fonts for the user-selected Stitch screen on November 16, 2026. The app serves these files locally.

Sources: https://fonts.google.com/specimen/Inter and https://fonts.google.com/specimen/Newsreader.

Redistribution licenses are included as `Inter-OFL.txt` and `Newsreader-OFL.txt`.

JetBrains Mono (400, 500, 600) is also bundled to match the Stitch counter, filenames and taxonomy labels. License: JetBrainsMono-OFL.txt. Source: https://fonts.google.com/specimen/JetBrains+Mono.
